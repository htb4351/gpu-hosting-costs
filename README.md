## “stable diffusion hosting” 到底是什么意思

这个短语背后隐藏着两种产品，它们的定价方式截然不同。第一种是按时计费的云端 GPU：你在公有云上部署一台 NVIDIA GPU 虚拟机——Vultr 是最典型的例子，你可以在其仪表盘上跨 30 多个地点启动和销毁 GPU 实例——并仅支付机器存在期间的费用。第二种是按月计费的独立 GPU 服务器：来自 CloudClusters、Database Mart 或 Rollin Host 等主机的固定价格服务器，通常具有无限流量带宽，且 GPU 仅供你使用。

## 每种 Stable Diffusion 模型实际需要多少 VRAM

8GB 足够 SD 1.5 和 2.x 使用；SDXL 至少需要 12–16GB 才能获得良好的体验；而 SD 3.5 Large 则确实需要 40GB 以上。模型托管商发布的兼容性数据在这方面相当一致：

| 模型 (fp16 大小) | 舒适 VRAM | 值得了解的信息 |
| --- | --- | --- |
| SD 1.5 (~4.3 GB) | 8 GB | LoRA + ControlNet 运行良好；AUTOMATIC1111 是常用的 UI |
| SD 2.x (~5.2 GB) | 8 GB | 流程与 1.5 系列相同 |
| SDXL base (~6.8 GB) | 12–16 GB | ControlNet 需要 SDXL 版本的模型；ComfyUI 是通用搭配 |
| SD 3 Medium (~10 GB) | 24 GB | RTX 4090 / 5090 级别 |
| SD 3.5 Large (~20 GB) | 40 GB+ | A100-40GB / RTX 5090 级别；24GB 比较吃力 |

在你购买之前有一个数据值得参考：Database Mart 为其自有硬件发布的基准测试显示，RTX 4090 在 512×512（20 步）下最高可达约 39.7 it/s，而较新的 RTX 5090 在 1024×1024 下为约 1.8–1.85 it/s。分辨率不同，所以将它们视为参考点——但这一差距解释了为什么在 1024² 下的 SDXL 感觉上与在 512² 下的 SD 1.5 完全不同。他们给出的实用建议与此吻合：对于 SDXL 和高分辨率工作，12GB 的 VRAM 是舒适度的门槛。

实用的结论是：不要购买超出你模型需求的显卡。为 SD 1.5 购买 A100 是浪费钱；尝试在 8GB 上运行 SD 3.5 Large 则会浪费时间。

## 对比页面忽略的细节

有四个实际细节很少出现在营销表格中，但每一个都会影响你的账单或产出。

首先，计费与实例存在相关，而非活动。在按小时计费的云上，只要实例存在，计费器就会运行，无论它是否在做任何事情。项目结束后，销毁机器，而不要让它闲置。快照先保存好你想保留的任何内容，因为销毁实例会删除其磁盘。这引出了第二点：磁盘会填满。SDXL checkpoint 每个约 6.8GB，SD 3.5 Large 约 20GB，LoRA 和输出会在此之上堆积。将任何有价值的内容推送到服务器之外或进行快照。

第三，在围绕某个模型标准化之前检查许可证。SD 1.5、2.x 和 SDXL 使用 CreativeML OpenRAIL 许可证发布；SD 3 和 3.5 带有更严格的条款。如果你要出售输出结果，这很重要。

第四，带宽。独立主机提供不限量的 100Mbps 端口；Vultr 则包含每月流量配额，且各套餐有所不同。为用户提供生成的图像属于轻量流量，但如果你要运营一个公开应用，请查看你所在套餐的配额，而不是凭空假设。

## 常见问题

**我可以在普通的廉价 VPS 上运行 Stable Diffusion 吗？**
不能。这些套餐仅提供 CPU，对于图像生成来说慢得不切实际。你需要一个具有真实 VRAM 的 CUDA GPU，这也是为什么每个认真的 Stable Diffusion 托管选项都以显卡为中心。

**8GB 的 VRAM 够用吗？**
对于 SD 1.5 和 2.x，是的。对于 SDXL，它在优化下可以运行，但 12GB 是舒适度的门槛，16GB 更佳。对于 SD 3.5 Large，不行——你需要看看 48GB 的档位。

**ComfyUI 或 AUTOMATIC1111 — 哪个更好？**
取决于你的模型。对于 SD 1.5/2.x 的简单性，AUTOMATIC1111 胜出。对于 SDXL 和 SD 3.5 的多阶段流程，兼容性表一致指向 ComfyUI。你可以随时安装两者并在同一个服务器上切换。

**如何控制 Vultr 的账单？**
选择能满足你模型需求的最小 VRAM，用完即销毁（先快照），并留意套餐的流量配额。一个按小时计费的 4090 如果每天用于渲染两小时，其费用与全天候运行大不相同。
